## 决策背景

8/12 审计发现 daily_price_latest.parquet 混入三种复权状态 + 腾讯 fqkline 负价格 bug，
fwd return 计算被污染。需要统一数据源与复权策略。

## 决策内容（用户拍板）

1. **腾讯 kline 是唯一数据源**（`kline/kline` 无复权参数，取原始价）
   - 理由：实测稳定、无 GFW 问题（akshare 东财接口被墙 ProxyError）、无负价格 bug
   - **有问题直接退出，不 fallback**（网络故障率 >5% 抛错；退市股 day 空数组正常跳过）
   - `fqkline/get` + `qfq` 永久禁用（BANNED，代码注释 + 单测守卫）
   - 新浪/akshare 路径废弃：`--source=sina` 直接 FAILED

2. **全库存储不复权原始价**
   - 理由：三源均提供原始价；原始价是本源，可推导任何复权价；
     前复权价会随最新除权漂移，历史研究不可比
   - 复权因子表独立存储 `adj_factor.parquet`（akshare qfq-factor）
   - 计算层按需：`close_qfq = close_raw / qfq_factor`

3. **fwd return 计算规范**：
   - 因子研究用资金流自带 `change_pct`（官方日涨跌幅）构造合成价格序列算 fwd
   （见 `diag_money_flow_ic.py::_build_adj_price`）— 天然复权安全
   - 用 daily_price 原始价算 fwd 必须先除权因子调整

## 兼容性影响
