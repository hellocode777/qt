## 决策

**Decision**：Layer 之间采用 Direct Call，不引入 Event Bus。

**Why**：Event Bus 最大的问题不是"写"，而是"隐藏流程"——到后来没人知道为什么会执行，Debug 极其困难。Direct Call 让执行顺序清晰可见。符合 Rule 28（不要为了未来可能发生的需求而增加抽象）。
