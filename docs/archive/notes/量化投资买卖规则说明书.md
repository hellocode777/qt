四、止损以后又涨回来怎么办？
这是整个系统最重要的哲学之一。
很多投资者都会问：
如果止损以后，它又涨回来了怎么办？
答案是：
这种情况一定会发生。
但：
止损从来不是预测未来。
止损管理的是：
未知风险。
站在触发止损的那一天，
未来只有两种可能：
路径 A：
后来涨回来了

路径 B：
后来继续暴跌

任何人都无法提前知道。
因此：
系统选择：
用一次较小的亏损，
避免一次不可控的大亏损。
这是：
Risk Management。
不是：
Prediction。

如果后来真的涨回来了怎么办？
系统不会因为过去发生过止损，就永久将其排除在投资范围之外。
止损只是一次风险控制行为，而不是对股票未来价值的永久否定。
后续每一个调仓日，系统都会重新对全市场进行统一评估。
如果股票重新满足策略的 Alpha 条件，重新进入目标组合（Target Portfolio），系统将按照正常买入规则重新建仓。
结论
系统不会因为过去发生过止损而产生任何"记忆"或"偏见"。
每一次调仓都是一次全新的评估。
是否重新买入，
完全由：
当前模型预测结果
决定。
而不是：
过去是否持有、
是否止损、
是否盈利。

八、最终设计哲学
Strategy Engine 每天负责回答："今天最值得持有哪些股票？"；Risk Manager 每天负责回答："哪些股票必须离开？"；Portfolio Manager 只在调仓日负责回答："今天需要如何调整组合？"；Decision Layer 最终负责人工审核与执行。
整个系统始终坚持四个原则：
Model Driven —— 一切投资决策由模型驱动，而不是人为预测。
Risk First —— 风险控制优先于 Alpha。
Stateless Decision —— 每一次调仓都是一次全新的评估，历史持仓、历史止损不会影响未来决策。
Human in the Loop —— 平台生成建议，最终交易始终由投资者确认执行。

from dataclasses import dataclass, field
from enum import Enum, auto
from typing import List, Dict, Optional

class Priority(Enum):
    CRITICAL = 1  # ST, 退市, 爆雷
    HIGH = 2      # 硬止损 (-10%)
    MEDIUM = 3    # 流动性/停牌
    LOW = 4       # Rank Drop, Position Resize

class TradeReason(Enum):
    STOP_LOSS = "STOP_LOSS"
    RISK_EVENT = "RISK_EVENT"
    RANK_DROP = "RANK_DROP"
    NEW_ENTRY = "NEW_ENTRY"
    REBALANCE = "REBALANCE"

@dataclass
class TradeRecommendation:
    symbol: str
    action: str  # "BUY", "SELL", "REDUCE"
    priority: Priority
    target_weight: float
    reasons: List[TradeReason] = field(default_factory=list)
    execution_time: str = "NEXT_OPEN"  # 次日开盘

class EnginePipeline:
    def __init__(self, config: PMConfig):
        self.config = config

    def run_daily_pipeline(
        self,
        is_rebalance_day: bool,
        current_holdings: Dict[str, float], # {symbol: weight}
        target_portfolio: Dict[str, float], # {symbol: weight} from Strategy Engine
        risk_triggers: Dict[str, List[TradeReason]] # {symbol: [reasons]} from Risk Manager
    ) -> List[TradeRecommendation]:

        recommendations: Dict[str, TradeRecommendation] = {}

        # -------------------------------------------------------------
        # 1. Risk Manager (每日必检，优先级最高)
        # -------------------------------------------------------------
        for symbol, reasons in risk_triggers.items():
            if symbol in current_holdings:
                prio = Priority.CRITICAL if TradeReason.RISK_EVENT in reasons else Priority.HIGH
                recommendations[symbol] = TradeRecommendation(
                    symbol=symbol,
                    action="SELL",
                    priority=prio,
                    target_weight=0.0,
                    reasons=reasons,
                    execution_time=self.config.stop_loss_execute
                )

        # -------------------------------------------------------------
        # 2. Portfolio Manager (仅调仓日运行)
        # -------------------------------------------------------------
        if is_rebalance_day:
            target_symbols = list(target_portfolio.keys())
            rank_map = {sym: idx + 1 for idx, sym in enumerate(target_symbols)}

            # 2.1 检查现有持仓的卖出逻辑 (Sell Buffer)
            for symbol, current_weight in current_holdings.items():
                if symbol in recommendations:
                    continue # 已经被 Risk Engine 强卖的不再重复处理

                rank = rank_map.get(symbol, 9999)
                if rank > self.config.sell_buffer_rank:
                    recommendations[symbol] = TradeRecommendation(
                        symbol=symbol,
                        action="SELL",
                        priority=Priority.LOW,
                        target_weight=0.0,
                        reasons=[TradeReason.RANK_DROP]
                    )

            # 2.2 检查新买入逻辑 (Buy Top N)
            top_n_targets = target_symbols[:self.config.target_top_n]
            for symbol in top_n_targets:
                if symbol not in current_holdings and symbol not in recommendations:
                    recommendations[symbol] = TradeRecommendation(
                        symbol=symbol,
                        action="BUY",
                        priority=Priority.LOW,
                        target_weight=target_portfolio[symbol],
                        reasons=[TradeReason.NEW_ENTRY]
                    )

        # -------------------------------------------------------------
        # 3. Priority Sort (出口统一按优先级排序给人类审核)
        # -------------------------------------------------------------
        final_list = list(recommendations.values())
        final_list.sort(key=lambda x: x.priority.value)
        return final_list
