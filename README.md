# QP — Quant Platform

A personal quantitative research & investment decision operating system.

> **Status**: Sprint 0 (Bootstrap) — Platform skeleton under construction.

## Quick Start

```bash
uv sync
uv run qp version
```

## Architecture

12-layer enterprise architecture. See `docs/` for full documentation.

## Development

```bash
uv run ruff format    # Auto-format
uv run ruff check     # Lint
uv run pyright        # Type-check
uv run pytest         # Run tests
```
